# 通用镜头 03 案例：从固定设备取下模块

这是一个明确选择 `CONTINUOUS_TAKE` 的中性示例，用于说明技术 Segment 如何使用台账、空间锁定、固定底板合成和真实尾帧续接。它不是“同场景都必须一镜到底”的通用要求。

## 镜头定义

| 字段 | 内容 |
|---|---|
| 镜头 ID | DEMO_EP01_SH03 |
| Scene / Shot / Setup / Take / Segment | DEMO_EP01_SC01 / SH03 / C2 / SH03_TK01 / SH03_SG03；CONTINUOUS_TAKE |
| 故事目标 | 主角从准备状态进入设备操作 |
| 入口状态 | 承接上一分段真实尾帧；主角面向操作区；可拆卸模块仍装在主设备接口上 |
| 主要动作 | 主角走近主设备，用右手握住模块，旋转解锁并向下取出 |
| 出口状态 | 主角右手持有已取下模块；模块尚未放到工作台 |
| 机位 | C2 右侧操作机位；保持主设备、辅助设备与工作台的空间关系 |
| 空间锁定 | SET-001_SPACE_v002；固定设备坐标/尺寸、C2 摄影机参数和右手触达检查均须 PASS |
| 真实尾帧 | 从 SH03_SG02 实际成片提取并验收 `DEMO_EP01_SH03_SG02_tail_v002_ACCEPTED`；SH03_SG03 直接使用，不以预制关键帧替代 |
| 场景素材 | `SET-001_C2_SCENE_ASSET_BUNDLE_v003_ACCEPTED`；首帧、峰值帧、尾帧全部引用同一素材包 |
| 禁止变化 | 不新增容器、垫片、手持工具或其他物件；固定设备不移位；角色造型不漂移 |
| 关键帧方法 | 复用已批准 C2 场景素材 + 独立角色/模块/阴影层；禁止生成、补画或重新采样场景 |
| 制作计划 | 一句话意图、开场策略、模型风险、色表、灰度和手机尺寸可读性均已锁定 |
| 提交前复核 | COLD_REVIEW；只读核对提示词、关键帧、数量、左右、触达和连续性 |
| 资产身份锁 | 唯一资产清单；全部输入为 ACCEPTED，文件与 SHA-256 校验通过，通行证引用闭合 |

## 台账摘录

- 角色 `CHAR-001`：锁定身体比例、服装、识别标记和左右手；入口时双手未持物。
- 场景 `SET-001`：沿用已批准母图和空间母版；固定关系为窗户、显示面板、主设备、辅助设备和连续工作台。
- 摄影机 C2：坐标 `[4.70,-2.40,1.45]`，目标点 `[3.40,1.05,1.15]`，50mm。
- 主设备：底面中心 `[3.20,1.10,0.90]`，尺寸 `[0.80,0.55,0.60]`。
- 峰值姿态右肩到模块接触点约 0.288m，小于最大有效伸展 0.38m；路径无遮挡且双脚有支撑。

| 道具 ID | 入口状态 | 变化动作 | 出口状态 | 因果要求 |
|---|---|---|---|---|
| PROP-MODULE-001 | 装在主设备接口 | 右手握住、旋转解锁、向下取出 | 右手持有 | 必须从设备上取出，不能先出现在工作台 |
| PROP-TOOL-001 | 固定操作区 | 无 | 不变 | 不得换位置或突然出现在工作台中央 |

## 五关结果

1. **剧本/剪辑/动作：PASS**。该 Shot 选择连续观察模块取下过程；四个动作节拍可在 7 秒内完成。若改用正常切镜，必须另建 Shot/Setup 并做剪辑连续性审核，而不是伪装成技术 Segment。
2. **资产/场景/空间/道具：PASS**。唯一资产清单覆盖角色、场景包、机位、空间母版、道具、真实尾帧、关键帧和蒙版；状态均为 `ACCEPTED`，文件 SHA-256 校验通过。资产台账、固定设备坐标与尺寸比例闭合；无新增物件。
3. **角色/机位/触达：PASS**。右手操作，C2 参数锁定；设备左右关系保持，右手实际可触及模块。
4. **关键帧/Animatic：PASS**。先验收 SG02 实际成片真实尾帧，再作为 SG03 首帧；三帧由同一 C2 底板分层合成。角色、模块和接触阴影为可变层，固定设备为保护区。Pixel Lock 及 7 秒预演通过，并与 SG02 连续播放无切点、无动作倒退。
5. **放行/验收：PASS**。正式交接与复核通过后才放行；成片按 0.4 秒生成 Contact Sheet，检查接缝邻帧并实际观看动态、试听音频，再复核叙事、身份、空间、物理接触、道具因果和伪影。

## 关键帧与差异区域

| 时间 | 帧 | 状态 |
|---|---|---|
| 0:00 | 首帧 | 与上一分段尾帧的站位、服装、光线和设备布局一致；模块仍装在设备上 |
| 0:03–0:04 | 峰值帧 | 右手正确握住模块，旋转方向和手物接触清楚 |
| 0:07 | 尾帧 | 模块已离开接口并由右手持有；工作台无新增物件 |

相邻关键帧另做 Pixel Lock：只把角色、模块轨迹、接触阴影和必要遮挡变化涂白；主设备、辅助设备、显示面板、窗户和未动作物件保持黑色保护区。正式放行要求保护区像素完全一致。

## 必须阻断的情况

- 资产不在唯一清单、状态非 `ACCEPTED`、文件缺失或 SHA-256 不匹配；
- 覆盖旧文件但沿用旧版本或旧引用；
- 工作台出现无来源物件；
- 模块在首帧已位于工作台或复制成两份；
- 使用了错误的持物手；
- 主设备与辅助设备交换位置；
- 固定设备坐标、尺寸比例或 C2 摄影机参数漂移；角色通过拉长肢体或悬空才能触及模块；
- 在同一已批准连续 Shot 内无设计地插入切点，或更改 Take/Segment ID 规避续接；正常新 Shot/Setup 不属于此项；
- 使用预制中间关键帧替代 SG02 实际尾帧，造成姿态回跳或动作重新开始；
- 尾帧模块无动作地消失或又装回设备；
- 为塞入后续动作导致节奏或物理过程不成立。
