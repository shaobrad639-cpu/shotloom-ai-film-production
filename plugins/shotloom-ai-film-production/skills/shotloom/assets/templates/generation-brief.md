# 正式生成交接包

## 身份与规格

- 通行证版本 / 状态：
- sequence / scene / shot / setup / take / segment：
- 输出资产契约 / 校验报告：
- 交付物类型：CLEAN_PLATE / CHARACTER_LAYER / PROP_LAYER / EFFECT_LAYER / FOREGROUND_LAYER / COMPOSITE_KEYFRAME / STORYBOARD_PANEL / VIDEO_SHOT
- 必须元素 / 禁止元素：
- 背景模式 / Alpha / 图层角色 / 允许烘焙元素：
- 连续性模式 / 与上一镜头关系：
- 目标模型与控制能力：
- 制作模式 / 风险等级 / 制作路线：
- 核心风险小样与通过证据：
- 参考策略：FIRST_FRAME_ONLY / FIRST_AND_LAST / MULTI_KEYFRAME / VIDEO_REFERENCE / COMPOSITE_INPUT
- 最小参考理由 / 是否要求精确出口：
- 模型原生时长 / 时长指令服从度 / 剪辑目标时长：
- 时长控制模式：MODEL_NATIVE_THEN_SELECT / TARGET_DURATION_IF_SUPPORTED
- 画幅 / 帧率 / 分辨率 / 色彩空间：
- 参考优先级与资产版本：

## 状态与表演

- 镜头目的：
- 入口状态：
- 动作节拍与表演：
- 出口状态：
- 角色、服装、左右手、持物和视线：
- 道具出现/变化/离画因果：
- 主动作主体：
- 次要主体处理：固定合成 / 遮罩局部运动 / 独立生成 / 联合生成

## 摄影机与剪辑

- setup_id / 景别 / 高度 / 角度：
- 焦距或 FOV / 帧率与快门或运动模糊依据：
- 曝光 / 白平衡 / 焦点 / 景深：
- position_moves：
- translation / rotation / lens_change：
- 路径 / 方向 / 速度曲线：
- 起止构图 / 主体锁定 / 视差预期：
- 运镜动机：
- 轴线、视线、屏幕方向和剪辑关系：
- 需要的后期运动、稳定、变焦或合成：

## 场景与连续性

- 场景资产包 / 空间母版 / 制作方式：
- 图层、蒙版、静态锚点或几何证据：
- 固定设备与触达：
- 环境动态方向、强度和相位：
- 若为连续 Segment：上一实际视频、真实尾帧/尾部窗口、摄影机终态和验收报告：
- 若为正常切镜：上一实际视频尾部的位置、方向、速度、动作/环境相位、作用区域，以及动作匹配、光色与声音桥：

## 声音

- 对白 / 同步要求：
- 环境底 / 动作声：
- 音乐 / 静音 / 跨切点关系：

## 生成约束与验收

- 可观察不变量：
- 允许变化：
- 禁止变化：
- 关键状态 / Previs：
- 验收标准：
- 选段入点 / 出点 / `EDIT_READY` 判定：
- 真实尾部证据与时间线替换要求：
- 当前轮次 / 熔断条件 / 本轮改变的生产条件：
- method_id / 同方法尝试次数 / 换方法原因：
