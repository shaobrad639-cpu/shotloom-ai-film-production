# 生成输出资产契约

## 目的

每次调用生成模型前，先定义本轮交付物的身份。提示词描述画面内容，输出资产契约约束“本轮到底在生产什么”。两者缺一不可。

典型失败包括：需要无角色场景母版却得到综合海报；需要透明角色层却混入背景、文字或其他角色；需要关键帧却得到分镜板或信息面板。这些都属于交付物身份错误，不应进入后续合成或视频生成。

## 支持的交付物

| `deliverable_type` | 用途 | 固定要求 |
|---|---|---|
| `CLEAN_PLATE` | 无活动主体的场景底板 | 独立资产、场景背景、无透明、背景层、必须隔离 |
| `CHARACTER_LAYER` | 独立角色层 | 独立资产、透明背景、Alpha、角色层、必须隔离 |
| `PROP_LAYER` | 独立道具层 | 独立资产、透明背景、Alpha、道具层、必须隔离 |
| `EFFECT_LAYER` | 独立特效层 | 独立资产、透明背景、Alpha、特效层、必须隔离 |
| `FOREGROUND_LAYER` | 前景遮挡层 | 独立资产、透明背景、Alpha、前景遮挡层、必须隔离 |
| `COMPOSITE_KEYFRAME` | 已合成关键帧 | 合成画面、非透明、允许批准层共同出现 |
| `STORYBOARD_PANEL` | 分镜面板 | 规划产物，不得冒充正式画面资产 |
| `VIDEO_SHOT` | 正式视频镜头 | 视频镜头、完整合成、按通行证验收 |

不要用 `CLEAN_PLATE` 代替所有场景制作方法。移动摄影机可以使用 2.5D、3D、深度或几何资产，但每个实际生成或渲染输出仍需具有明确交付物身份。

## 生成前必填

复制 `assets/templates/generation-output-contract.json`，填写：

- `required_elements`：必须出现的对象或资产；
- `forbidden_elements`：不得出现的角色、场景、文字、边框、信息面板或未登记对象；
- `background_mode` 与 `alpha_required`；
- `baked_elements_allowed`：允许不可逆合并进输出的元素；
- `layer_role` 与 `isolation_required`；
- 画幅、分辨率、色彩空间、文件格式和文字策略；
- 参考优先级、审核人和审核证据。

必须与禁止元素不得重叠。独立素材必须隔离；透明图层必须要求 Alpha；正式 Shot 的交接契约必须是 `VIDEO_SHOT`。未经 `APPROVED / PASS` 的契约不能用于正式生成。

运行：

```bash
python3 scripts/validate_output_contract.py <输出契约.json>
```

## 生成后验收

先检查交付物身份，再评价画面质量。出现以下任一情况直接拒绝：

- 交付物类型错误；
- 缺少必须元素或出现禁止元素；
- 独立素材混入未批准背景、角色、文字或版式；
- 透明图层没有可用 Alpha，或边缘被背景污染；
- 图层角色错误或烘焙了未批准元素；
- 画幅、分辨率、色彩空间或文件格式不符。

身份检查通过后，才进入动作、环境、摄影机、连续性和审美验收。
