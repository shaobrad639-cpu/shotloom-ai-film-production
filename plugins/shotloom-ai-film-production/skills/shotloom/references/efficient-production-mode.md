# 高效短片制作模式

## 适用边界

`EFFICIENT_SHORT` 用于片长较短、剪辑结构已锁定、镜头数量有限、交付规格明确且不需要为长期复用建立完整角色系统的项目。它不降低资产身份、空间、动作因果、环境动态、连续性或交付标准；它减少重复审核、无效素材制作和低收益精修。

标准项目使用 `STANDARD`。项目包含大量复用角色、多角度精确表演、复杂对白口型、高规格 VFX 或长期系列资产时，不要仅因赶进度启用轻量路线。

## 三阶段执行

### 1. 一次锁定与变更审核

首次正式生产完成完整五关。后续轮次只重新审核新增、变更及受影响项目；已批准资产仍通过版本和 SHA 继承，不重复进行主观设计审核。

变更审核必须记录：继承的锁定项、实际变更、受影响检查以及是否需要全量复核。改变剧情状态、资产身份、空间关系、动作相位、机位或剪辑结构时，不能用“变更审核”绕过对应关卡。

### 2. 核心风险小样

只验证最可能导致整镜失败的动作、接触、转换、环境反应或摄影机路径。小样时长由风险决定，常见为 1–2 秒，但不写死；若风险依赖完整时间过程，小样必须覆盖整个风险区间。

`EFFICIENT_SHORT` 中 L2–L4 镜头必须有通过的小样；L1 可以 `N/A`，但要说明原因。小样不用于精修次要纹理。

### 3. 正式生成、集中验收与时间线替换

小样通过后制作完整镜头。一次列出主要缺陷并按根因分配给生成、合成、剪辑或后期，避免每轮只修一个表面问题。镜头通过后立即替换时间线占位素材，并播放所在 Sequence 或全片，优先保证所有镜头都有可剪版本。

## 制作路线

| 路线 | 适用情况 |
|---|---|
| `DIRECT_REFERENCE_VIDEO` | 短小有机动作；参考图直接驱动视频，允许模型完成中间运动 |
| `PLATE_PLUS_VIDEO_COMPOSITE` | 固定场景连续性要求高；动作候选与批准底板合成 |
| `KEYFRAME_GUIDED_VIDEO` | 起止状态、接触或动作落点需要控制；使用首尾或少量关键状态 |
| `RIG_OR_3D_CONTROLLED` | 高复用、复杂机位、精确交互，或低复杂度路线有证据地失败 |

选择能达到交付质量的最低复杂度路线。透明视频、视频参考、身份控制和背景保持能力必须以模型能力测试为准，不能假定产品支持。

使用 `RIG_OR_3D_CONTROLLED` 时说明复用收益、精确控制需求或前序路线失败证据。复杂方法不是默认的“更专业”。

## 风险等级

- `L1`：单一动作、固定或简单机位、低交互风险。
- `L2`：少量关键状态、可见接触或环境反应。
- `L3`：复杂转换、连续运镜、精确动作或高连续性风险。
- `L4`：决定作品观感的英雄镜头，允许专项技术投入。

工作量按风险和叙事价值分配，不平均精修所有镜头。

## 两次失败换方法

同一 `method_id` 最多尝试两次。达到限制或同一主要缺陷重复两次后，停止继续改写同类提示词，改变生产条件：换输入模式、换模型、改用固定底板合成、减少同时动作、拆镜、调整剪辑或升级控制技术。

只改提示词措辞不算换方法。换方法要更新 `method_id`、`previous_method_id` 和 `method_switch_reason`，并重置该方法的尝试计数。

## 缺陷分级与停止标准

- `C0`：交付物类型或关键资产错误，镜头不可用。必须返工。
- `C1`：故事不清、动作倒退、严重形变、明显漂移、接缝断裂。必须返工。
- `C2`：交付分辨率正常播放时明显影响观感。修复或记录接受依据。
- `C3`：适合在全片阶段统一处理的边缘、色彩或轻微闪烁。进入精修清单。
- `C4`：暂停逐帧才明显的低影响瑕疵。接受，不再返工。

镜头只有在 C0/C1 清零、C2 有结论、按实际交付分辨率和正常速度通过、并已回填时间线后才锁定。不得用分级掩盖角色身份、连续性、空间或动作因果错误。

## 整片优先

维护 `assets/templates/sequence-progress-board.md`。优先顺序为：补齐可剪版本 → 修复 C0/C1 → 替换最弱镜头 → 精修英雄镜头 → 统一处理 C3 → 最终调色、声音和交付 QC。
