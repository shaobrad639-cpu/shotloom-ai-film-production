# 场景资产、关键帧与画面锁定

## 原则

连续性来自受控资产和空间，不来自重复写“保持一致”。禁止在每张关键帧中让模型无控制地重新想象场景；但允许批准的固定底板、局部编辑、深度分层、2.5D、3D 渲染和新 Setup 渲染。

## 选择制作方式

- `EXACT_PLATE_COMPOSITE`：固定机位且直接复用同一底板；角色、活动道具、接触阴影和批准环境动态独立合成。保护区可要求 100% 像素一致。
- `STRUCTURAL_ANCHOR_CHECK`：固定或轻微变化画面，但存在颗粒、光照、重采样或模型渲染；检查固定锚点、透视、相对尺寸、色彩/曝光容差，不要求逐像素相同。
- `GEOMETRY_REPROJECTED`：移动摄影机；复用批准的深度、2.5D 或 3D 几何、材质和世界坐标，验证视差和重投影。
- `N/A`：关键帧不需要画面锁定时说明理由。

## 流程

1. 锁定场景资产包、分辨率、色彩空间、Setup 和空间母版。
2. 设计能验证动作的关键状态；不强制固定数量或“峰值帧”。
3. 按制作方式生成角色层、道具层、Rig/3D 渲染或受控局部编辑。
4. 合成并处理透视、遮挡、接触阴影和露出区域。
5. 运行对应的像素、锚点或几何检查。
6. 通过 Previs 后再生成正式视频。

允许变化蒙版只覆盖真实动作扫掠区、活动道具、接触阴影、必要遮挡与登记环境动态。保护区最低占比不是通用电影标准；应由实际构图决定，异常大蒙版需要说明。

## 返工

角色错误优先修角色或 Rig；道具错误修对应资产；遮挡/阴影错误修合成；场景母版本身错误则升级场景版本并做依赖影响分析。不要从已经漂移的整图中反向提取新的场景基线。
