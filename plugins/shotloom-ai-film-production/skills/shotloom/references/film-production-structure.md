# 电影制作层级、覆盖拍摄与摄影语言

## 制作层级

`Sequence → Scene → Shot → Setup → Take → Segment` 必须分开管理。场景描述叙事时空，镜头描述连续画面，Setup 描述摄影与调度方案，Take 是执行版本，Segment 只是生成工具的技术容器。

同一场景允许多个 Shot 和 Setup。只有明确设计为长镜头，或多个 Segment 要无切点拼成同一 Shot/Take 时，才使用 `CONTINUOUS_TAKE`。其余使用 `EDITORIAL_SHOT`，按剪辑连续性验收。

## 镜头与覆盖拍摄

镜头表至少回答：镜头承担什么信息；为何使用当前景别、角度和时长；人物/道具如何进出画；与前后镜头如何连接。覆盖拍摄可包含主镜头、正反打、双人镜头、过肩、反应、插入、特写和建立镜头；不要求每个场景具备全部覆盖，只保留剪辑真正需要的画面。

切镜时检查：

- 180 度轴与屏幕方向；越轴必须有建立、移动镜头或明确的方向重置。
- 视线匹配、动作匹配、人物站位与持物手。
- 30 度规则或足够明显的景别/构图变化，避免无意跳切。
- 光线方向、色温、曝光、时间、天气和环境动态相位。
- 对白、环境底、动作声和音乐能否跨切点连续或有意断开。

## 摄影机运动拆分

不要把运镜写成模糊审美词。分别登记：

- `translation`：`none / dolly / truck / pedestal / crane / orbit / tracking / handheld_path`。
- `rotation`：`none / pan / tilt / roll`。
- `lens_change`：`none / zoom_in / zoom_out / focus_pull / iris_change`。
- 路径、方向、起止位置、速度曲线、主体锁定方式、视差预期和叙事动机。
- 帧率、快门角度或等效运动模糊、曝光、白平衡、焦点和景深；同一剪辑段内无设计依据不得跳变。

`dolly` 是摄影机位移，会改变透视与视差；`zoom` 是焦距变化，不等价。希区柯克变焦需要相反方向的位移与变焦同步，必要时分两步生成或后期合成，不应只靠一个效果名称要求模型自行完成。

## 一镜到底与技术分段

长镜头是创作选择，不是场景默认值。`CONTINUOUS_TAKE` 内可以连续改变景别、焦点和摄影机轨迹，但不能出现未经设计的切点。若模型时长不足，将同一 Take 拆成多个 Segment：后一 Segment 使用上一 Segment 的实际稳定尾帧和尾部时间窗口，继承摄影机、动作、声音与环境相位。

## 声音与后期

镜头设计同时记录对白、环境底、动作声、音乐和静音意图。生成模型产生的声音不是自动可信来源；对白同步、空间感、噪声底和切点连续性必须在后期验收。需要合成、变速、稳定、去闪、遮罩、调色或声音修复时，记录为后期处理，不要伪装成模型一次生成成功。
