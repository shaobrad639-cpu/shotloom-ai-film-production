# 生成交接与重试

## 参考优先级

1. 已批准角色、场景、空间、道具与摄影机资产。
2. 当前 Shot 的关键状态、Previs 和镜头设计。
3. 上一镜头实际选用视频的尾帧、尾部窗口、位置、方向、速度和动作/环境相位；正常切镜用来设计入口，连续 Take 后续 Segment 直接用作生成起点并高于计划首帧。
4. 风格参考；只影响表现，不覆盖身份、空间和状态。

## 按模型能力路由

- 首尾帧或多关键帧模型：提交必要关键状态，不强制无意义的峰值帧。
- 仅首帧模型：减少同时发生的高风险动作，复杂接触可拆成新 Shot 或连续 Segment，二者必须明确。
- 纯文本模型：可用于概念或低风险 Previs；连续性要求高的正式镜头缺少视觉/空间依据时阻断。
- 能引用 3D/深度/运动控制的模型：优先提交批准几何与摄影机轨迹。

默认只提交实现镜头目的所需的最少参考。参考策略使用 `FIRST_FRAME_ONLY / FIRST_AND_LAST / MULTI_KEYFRAME / VIDEO_REFERENCE / COMPOSITE_INPUT`。只有精确出口、落点、接触或变形终态需要且模型实测支持时才增加尾帧；多关键帧必须对应不可省略的动作状态，不得把大量姿态当作可靠性的替代品。

多主体镜头先指定主动作主体。其他主体选择固定合成、遮罩局部运动、独立生成或联合生成；只有模型能力测试证明身份不会互换或形变时，才允许 `JOINT_GENERATION`。

先选择制作路线，再编译模型提示词。路线只使用 `DIRECT_REFERENCE_VIDEO / PLATE_PLUS_VIDEO_COMPOSITE / KEYFRAME_GUIDED_VIDEO / RIG_OR_3D_CONTROLLED`。优先采用满足质量要求的最低复杂度路线；模型是否支持透明视频、视频参考、角色身份控制和背景保持必须先验证。

## 交接内容

至少包含：层级 ID、连续性模式、与上一镜头关系、上一镜实际尾部证据、目标模型、输出资产契约与校验报告、输出规格、参考策略与优先级、模型原生时长、剪辑目标时长、场景资产与空间母版、主动作主体与次要主体处理、角色/道具状态、必要关键状态、摄影机计划、动作节拍、声音、环境动态、允许变化、禁止变化、后期计划、重试计数和验收标准。

时长使用两种模式：`MODEL_NATIVE_THEN_SELECT` 按模型稳定原生时长生成后选段；`TARGET_DURATION_IF_SUPPORTED` 只在实测证明精确控制可靠时使用。模型输出长于目标并不自动构成失败，进入 `EDIT_READY` 时必须记录真实入点、出点和选用时长。

输出资产契约先于提示词。它必须明确交付物类型、必须与禁止元素、背景模式、透明通道、图层角色、允许烘焙元素、隔离要求和技术规格。正式镜头交接使用 `VIDEO_SHOT`；场景母版、角色层、道具层、特效层和关键帧分别使用对应类型，不得用“生成一张图”代替资产身份。

摄影机计划必须分开写相机位移、旋转和镜头变化，并写路径、方向、速度曲线、主体锁定、视差与动机。不要把“推镜”和“变焦”当作同义词。

固定底板合成附 Pixel Lock；结构锚点模式附锚点和容差；移动摄影机附几何/深度与重投影或视差验证。`EDITORIAL_SHOT` 附剪辑连续性，`CONTINUOUS_TAKE` 后续 Segment 附真实尾帧续接。

## 失败归因

先检查是否为交付物身份错误：类型、必须/禁止元素、透明通道、素材隔离、图层角色或技术格式不符时直接拒绝，不能把它当作普通画面瑕疵继续修补。身份正确后，一次列出本轮主要缺陷并判断输入冲突、参考错误、资产/空间漂移、动作设计、摄影机、技术接缝、声音还是偶发伪影，再决定局部修复、合成/剪辑修复、重做关键状态、重生 Segment 或重生 Shot。同一方法或同一缺陷达到两次限制后必须改变生产条件；只改提示词措辞不算换方法。不得用转场掩盖未批准的接缝，也不得用增加抽卡次数替代设计修正。
