# 环境动态锁

## 边界

固定机位只表示摄影机参数不变，不表示环境必须冻结。场景连续性同时包含：

- **静态空间连续性**：建筑、岩体、固定设备、地平线/天际线、光源锚点、总体构图和未动作资产不得漂移。
- **动态时间连续性**：水、云、雾、雪、雨、火焰、烟尘、植被、蒸汽或光照呼吸等已登记区域必须按物理规律持续演化。

环境动态不是放宽场景锁定。只有已登记并受蒙版约束的区域可以变化；其余像素或几何仍受 Pixel Lock/空间锁定保护。

## 强制五步闭环

只要正式画面中可见的环境包含水、云、雾、雨雪、烟火、植被、蒸汽、光照变化或其他应持续运动的元素，就必须在角色加入前完成环境动态控制。顺序不得颠倒：

1. **场景母版**：先锁定静态空间、地平线/天际线、固定设备、关键地貌、总体构图和主光源锚点。母版防止空间漂移，不承担动态表演。
2. **环境动态分层**：把每个动态区域拆成稳定图层或受控模拟区域，登记资产引用、蒙版、运动类型、方向、速度、强度和入口相位。动态区域不得依靠每帧整图重绘产生。
3. **无角色环境预演**：不加入角色、车辆或活动道具，先播放环境本身，验证自然运动、静态锚点、循环和时间相位。预演未通过时不得生成正式角色镜头。
4. **角色与环境合成**：按动作建立反应耦合，例如接触、位移、风压、重量、热量或光线遮挡对相应环境层的影响。没有可见交互时可标 `N/A`，但必须说明原因。
5. **完整镜头验收**：每个镜头都要同时检查角色/主体动作、环境运动、摄影机运动、角色/主体与环境之间的因果关系，以及静态空间和跨镜头或技术分段的相位连续性。某项确实不动时标记有依据的 `N/A`，不得默认为已通过。

这五步是第二关的强制子关卡 `gate_2b_environment_dynamics`。真正没有可见动态环境时可以用带证据的 `N/A`；画面存在本应运动的环境元素却未登记或未预演时必须 `BLOCKED`。

## 登记内容

每个需要环境动态控制的 Shot/Take 使用 `assets/templates/environment-animation-lock.md`，记录：

- 静态保护资产与锚点；
- 每个动态区域的稳定资产引用、允许变化蒙版和运动类型；
- 总体运动方向和强度范围；
- 入口相位、计划出口相位和与上一分段的相位承接；
- 是否允许周期运动；即使允许周期，也禁止在技术分段接缝无因果地重置循环；
- 无角色环境预演的版本、播放证据和结论；
- 角色、车辆、活动道具或摄影机运动与环境区域之间的反应耦合；
- 冻结检查、静态漂移检查及证据。

常见动态的方向应使用可观察描述，例如水面由远向近推进、云层向画面左侧缓慢漂移、雾受角色/物体气流向两侧散开。强度应描述稳定范围和允许变化，不只写“自然运动”。

## Pixel Lock 分区

静态同机位仍执行 Pixel Lock，但保护区不包含已登记动态区域。动态区域的蒙版必须精确覆盖必要范围并登记到资产清单；不得把整片天空、地面或背景涂白来掩盖漂移。

动态区域不要求像素相同，而要求：边界位置合理、运动方向一致、速度/强度无无因果突变、纹理不复制跳变、相位连续。动态区域内的固定锚点仍应另设保护子区。

## 分段续接

同一连续 Take 的技术 Segment 续接时，真实尾帧不仅锁定角色和道具状态，也锁定环境动态的可观察相位。正常切镜可在合理时间连续性内改变构图，但环境方向、天气和运动逻辑仍须连贯。

若单张尾帧不足以判断速度和方向，应同时保留尾帧前的短时间窗口或运动测量证据。无法判断环境相位时保持 `BLOCKED`，不能假设循环自然衔接。

## 生成后验收

对每个登记动态区域检查：

- 未连续多秒完全静止，除非剧本有明确静止原因；
- 无跳变、倒放、速度突变、纹理瞬移或循环重启；
- 运动方向与强度符合登记；
- 分段接缝前后相位连续；
- 动态区域之外的静态锚点没有漂移。
- 角色、物体或摄影机引发的环境反应符合已登记的方向、延迟、范围和衰减；
- 环境运动没有因为角色入画而停止、重启或变成另一套运动规律。

`freeze_check` 通过只证明动态环境没有被冻结；还必须让 `static_drift_check` 通过，证明动态没有带动固定场景漂移。两者缺一不可。

## N/A

没有任何可见环境动态的场景可标记 `N/A`，但必须说明这是有意的视觉设计。只要画面包含本应持续运动的水、云、雾、雪、火焰、烟尘、蒸汽或风动元素，就不能用 `N/A` 规避动态分层、无角色环境预演或冻结检查。
