# 真实尾帧续接

## 适用范围

本规则只覆盖同一 `shot_id + take_id` 内连续拼接的技术 Segment。正常切镜以动作、视线、屏幕方向和状态连续性连接，不要求新镜头首帧复制上一镜头尾帧。

## 流程

1. 从上一 Segment 最后稳定区间提取最后一张完整画面，并保留尾部短时间窗口；记录视频版本、时间码、帧号和方法。
2. 对照批准出口状态，检查角色身份与动作相位、道具和接触、场景/设备、摄影机、图像质量、声音与环境动态。
3. 固定底板合成按 Pixel Lock 验证；3D/2.5D 或重新渲染按几何、锚点、构图与容差验证。
4. 通过后登记为 `ACTUAL_RENDERED_TAIL / ACCEPTED`，作为下一 Segment 的最高优先级入口证据。
5. 下一 Segment 只描述尚未完成的后续动作，并明确禁止回到较早姿态或重复已完成接触。

单帧无法证明速度、运动方向、声音或环境相位时，尾部时间窗口是必需证据。真实尾帧已有身份、空间、设备、道具或动作漂移时必须拒绝并返工；不能为了连续而延续错误。
