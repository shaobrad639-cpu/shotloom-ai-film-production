# 前期制作、独立复核与质量控制

## 错误前置原则

按成本从低到高发现错误：文字与镜头表 → 低成本构图/Animatic → 关键状态 → 正式视频 → 后期。关键未知、冲突或无法验证的条件按 `BLOCKED` 处理；低风险创作选择可以登记为假设并在 Previs 验证。不能用增加生成次数代替设计和审核。

## 项目启动卡

开工前使用 `assets/templates/project-brief.md`，至少确认：一句话意图、片长、画幅、帧率、分辨率、音乐/对白/字幕、交付目标、模型能力、预算上限、按量计费服务及授权范围。价格、模型 ID 和平台限制放在项目配置中，不写死进通用 Skill。外部付费调用必须在提交前获得用户对具体调用或清晰预算范围的授权。

## 故事与模型可拍性

逐个转折检查“为什么发生、资产从哪里来、角色是否够得着、现实或设定中是否成立”。有旁观者时，把反应按问题 → 主角处理 → 旁人反应排列，并明确先后。开场策略必须说明最早的叙事吸引点，但不强制所有作品使用夸张钩子。

建立模型风险记录，重点检查：人物交叉、小物件精细操作、画面文字、镜面/倒影、左右不对称特征、同镜换光、一个角色连续多动作、俯拍遮脸、配角过多或多人同姿势。风险不是自动否决；必须通过改动作、减少参与者、分层合成、局部编辑或更合适的模型能力缓解。

## 视觉方向锁定

正式关键帧前锁定场景色表、强调色、主体与背景的灰度层次、构图安全区、目标观看尺寸可读性、动作落点留白、运动主体和摄影机运动动机。参考片可以用于量取景别、人物进出画比例、运动节奏和构图关系，但不能覆盖本项目的场景空间与资产身份。

“每个镜头换角度”和“同一场景绝不切镜”都不是通用规则。镜头变化必须服务信息、情绪或节奏；允许主镜头、反打、反应、插入和特写，但要通过轴线、视线、屏幕方向、动作匹配和声音连续性检查。静止也可以是有意节奏。

## 计划关键帧策略

固定底板合成可先制作信息最完整的一帧，再通过局部图层编辑得到其他计划帧。若使用 3D/2.5D、角色 Rig 或受控重新渲染，则锁定场景身份、空间母版、材质、摄影机与色彩，而不是强行复用同一像素。

只有同一连续 Take 的后续技术 Segment 才必须使用上一 Segment 实际成片中验收通过的真实尾帧。正常切镜使用上一镜头实际尾部作为状态连续性证据，但新镜头首帧按新 Setup 设计。慢推等摄影机变化可从批准的高分辨率场景/几何资产重投影、渲染或裁切得到，并验证分辨率、视差和构图。

## 七段式生成契约

1. 视觉风格：只描述已批准风格及需保持的线条、材质和色彩。
2. 镜头：时长、景别、机位、连续运镜；固定机位明确不推不拉不摇且不切镜。
3. 构图与配色：角色和设备位置、光线、色表及画面方向。
4. 角色与道具：身份、服装、数量、持物手和恒定状态。
5. 逐时间段动作：原因、先后、画面左右、接触点、禁止接触对象、起止状态。
6. 声音：只安排有可见或已登记来源的声音；音乐、对白和后期音效分开声明。
7. 约束与后期：先写可观察的不变量，再写必要禁止项；注明连续性模式、资产数量、场景制作方式和计划后期。真实尾帧只在连续 Take 后续 Segment 中填写。

开场保持与结尾稳定时间由模型/剪辑配置决定。逐秒时间是动作节拍目标，不假定生成模型能逐帧精确遵守；正式节奏仍由生成后剪辑验证。

## 独立只读复核

正式生成前使用 `assets/templates/independent-preflight-review.md`。普通镜头可由制作流程中的明确复核完成；连续性高风险、复杂动作或高成本生成建议使用隔离上下文复核。逐项核对提示词与关键帧的位置、左右、颜色、人数、数量、服装、表情、机位、背景、动作因果、触达和前后连续性。结论只能为 `PASS` 或 `BLOCKED`；后者必须列出最小修正项。

独立复核是一种上下文隔离要求，不强制必须使用子代理；可以由另一位人员、另一会话或明确清空先验结论的复核流程完成。

## 生成后抽检

使用 `assets/templates/acceptance-sampling.md`。默认每 0.4 秒抽取一帧生成 Contact Sheet；可根据运动速度缩短间隔。另以全分辨率检查首帧、动作峰值、稳定尾帧，以及每个技术接缝前后至少 3 帧。检查故事可读性、动作重复/倒退、人物身份、道具数量、方向、接触、穿插、闪烁、形变、色彩和场景漂移。

动态手感必须实际播放观看，声音必须实际试听或通过音频分析获得证据。工具或审核者未实际访问某种模态时，应记录 `未检查` 并阻断需要该结论的验收；静音作品可将音频标为 `N/A`，但需说明设计依据。

## 修复决策

按成本和影响范围从小到大评估：裁掉问题边缘帧；批准图层内局部修复；后期合成；重做关键帧；仅重生当前分段；整段返工。剪裁或后期修复不能掩盖动作状态丢失、资产漂移、空间错误或真实尾帧错误。只要修复改变状态或连续性，就必须退回相应关卡。

高效短片模式先按 C0–C4 分级。C0/C1 必须清零；C2 修复或记录接受依据；C3 进入全片统一精修；C4 接受。评判必须基于实际交付分辨率和正常播放速度，同时保留合理的后期裁切与调色余量。镜头通过后立即替换 Animatic 占位并播放所在 Sequence 或全片，防止单镜头过度精修拖延整体完成。
